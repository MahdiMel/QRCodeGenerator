# QR Code Generator 📱

**Project 6/7 of the challenge**

An interactive QR code generator built entirely on the frontend. This application allows users to convert any text or URL into a downloadable QR code instantly.

https://mahdimel.github.io/QRCodeGenerator/

## ✨ Features
* **Instant Generation:** Creates QR codes in real-time.
* **Modern UI:** Styled with Tailwind CSS for a premium, responsive card layout.
* **One-Click Download:** Integrated button to save the generated QR code directly as a PNG.
* **Zero Dependencies:** Runs entirely in the browser using HTML, JavaScript, and QRCode.js—no backend required.

## 🛠️ Built With
* HTML5 & Vanilla JavaScript
* Tailwind CSS (via CDN)
* [QRCode.js](https://davidshimjs.github.io/qrcodejs/)

## 💻 Setup
No installation needed. Simply download or clone the repository and open `index.html` in any modern web browser.
